# OPPO / ColorOS 手动清单

实测机型：Find N6（ColorOS 16.0.9）、Find X10 Pro Max（ColorOS 17）。一加、realme 的 ColorOS / 氧 OS 结构相近，入口名可能不同。
符号：🔴 关掉　🟢 保留　⚠️ 注意

---

## 1. 系统：广告跟踪

**路径**：设置 → 隐私 → 设备标识与广告 → 广告跟踪

- 🔴 每个 App 一个开关，没有总开关。数量随安装应用和机型变化：手机可能上百个，OPPO Pad Mini 社区实测约 26 个。
- ⚠️ 部分版本需向下滚动到「更多」分组，才看到「设备标识与广告」；「更多」未必是可点击的子页。
- ⚠️ 新装的 App 默认打开，装了新 App 要回来关一次。

## 2. 负一屏（速览）

**路径**：桌面从左边缘向右滑 → 左上头像 → 设置

- 🔴 搜索框提示词
- 🔴 推荐服务 → 轮播推荐 → 选「不显示」
- 🔴 热点资讯
- 🟢 服务动态（出行、生活提醒）、快捷服务
- ⚠️ 「推荐服务」总开关不要关：会删掉天气、步数、清理卡片。

## 3. 下拉搜索

**路径**：桌面中间向下滑 → 搜索页底部「设置」

| 子页 | 🔴 关掉 | 🟢 保留 |
|---|---|---|
| 搜索范围 | 榜单、小说、购物、个性化推荐、精选资讯 | APP内搜索、搜索建议、小程序、AI 搜索、便捷服务 |
| 首页卡片管理 | 未下载应用推荐、应用建议小卡、探索发现、活动皮肤 | 应用建议、本机资产推荐 |
| 功能管理 | 搜索框提示词 | — |
| 账号与隐私 → 隐私 | 个性化推荐 | — |

- ⚠️ 「APP内搜索」必须开着，关了搜不到本机应用。
- ⚠️ 搜索页顶部会提示「搜索结果受限，开启全部搜索范围」，不要点「去开启」。
- ⚠️ 搜索设置子页往下拉会退出，翻页用手指上滑。

## 4. 软件商店

**路径**：软件商店 → 我的 → 右上齿轮

| 子页 | 🔴 关掉 | 🟢 保留 |
|---|---|---|
| 隐私 | 个性化推荐 | — |
| 服务管理 | 首页悬浮活动图标、首页活动弹窗、首页顶部轮播卡片、底部活动专区、游戏专区各项、游戏详情页活动卡片等，共 30 多项 | 帮助与客服、应用安全、应用工具、存储空间清理、我的资产、安全守护、小i客服、应用使用记录、首页 AI 搜索、自动检测风险应用 |

- ⚠️ 「我的」页有头像和手机号，截图时避开。
- ⚠️ 服务管理全关后，「开机必备」弹窗仍会出现。

## 5. 浏览器

**路径**：Find N6：底部 ☰ → 齿轮；Find X9 Ultra：底部「我的」→ 设置

- 🔴 主页设置 → 页面布局 → 选「简洁」（资讯流和活动图消失）
- 🔴 隐私 → 广告管理 → 开屏广告、资讯列表广告（摇一摇广告随之变灰）
- 🔴 个性化推荐
- ⚠️ 搜索框里的轮播热词没有开关。

## 6. 主题商店

**路径**：主题商店 → 我的 → 齿轮

- 🔴 服务管理 → 消息与广告 → 消息通知、开屏广告
- 🔴 隐私 → 个性化推荐设置 → 个性化推荐
- 🟢 「全部服务 / 基础服务」保持「全部服务」

## 7. 视频（OPPO 视频）

**路径**：视频 → 我的 → 设置 → 个性化内容管理

- 🔴 个性化推荐

## 8. 游戏中心

**路径**：游戏中心 → 我的 → 设置 → 隐私开关设置 → 个性化推荐管理

- 🔴 个性化推荐

## 9. 小布建议

**路径**：设置 → OPPO AI → 小布建议 → 内容资讯

- 🔴 资讯服务
- 🟢 快递、航班、日程提醒，商圈服务

## 10. 营销通知

**路径**：设置 → 通知与状态栏 → 通知管理 → 选 App → 点渠道名

- 🔴 每个 App 里叫「内容与营销」的渠道。支付宝、京东、美团、大众点评、小红书、闲鱼、抖音、快手、得物、QQ、腾讯会议、天气、下拉搜索都有。
- 🔴 系统消息「精彩推荐」、云服务「专享优惠」「权益福利」、钱包「福利通知」、视频「重要营销信息」、负一屏「最新资讯通知」。
- 🟢 同一个 App 里的订单、物流、更新、安全、聊天渠道。

<p align="center"><img src="../../images/channel-off.png" width="420" alt="内容与营销渠道关掉"></p>

用电脑跑：`run.py chan-scan` 列出全部候选，`chan-off` 一次关完，27 个渠道约 60 秒。

刚重置的设备可能还没有创建很多通知渠道，空清单不表示没有广告；正常使用后可再次扫描。

## 11. 广告包（要 adb，要你同意）

| 包 | 作用 | 挂起后 |
|---|---|---|
| `com.opos.ads` | OPPO 广告服务 | 正常 |
| `com.heytap.pictorial` | 乐划锁屏 | 锁屏杂志消失 |

## 12. 快应用（要 adb，要你同意）

| 包 | 作用 |
|---|---|
| `com.nearme.instant.platform` | 快应用平台，接管 `hap://` 链接 |
| `com.oppo.instant.local.service` | 快应用本地服务 |
| `com.nearme.instant.card` | 快应用卡片（部分机型有） |

用电脑跑：`run.py quickapp` 检测，`quickapp off` 关闭。见 [07-快应用](../07-快应用.md)。

- ⚠️ 不要挂 `com.heytap.quicksearchbox`（下拉搜索）和 `com.coloros.assistantscreen`（负一屏）。

## 不同机型的差异

| 项 | Find N6（16.0.9） | Find X9 Ultra（16.0.10） | Find N3 典藏版（16.0.5） | 一加 Ace 5（PKG110，16.0.10.500） |
|---|---|---|---|---|
| 浏览器设置入口 | 底部 ☰ → 齿轮 | 底部「我的」→ 设置 | 待补 | 底部栏图标无文字标注，无法按文字定位；可直达 `am start -n com.heytap.browser/.settings.component.BrowserPreferencesPage` |
| 商店设置页 | 有「隐私」「服务管理」 | 有 | 齿轮进去是「应用与服务」，入口待补 | 无「隐私」「服务管理」子页；个性化推荐藏在「账号与隐私 → 隐私授权管理 → 个性化推荐」子页（二级入口是跳转箭头，不是开关） |
| 视频、游戏中心 | 我的 → 设置 | 找不到「我的」，待补 | 待补 | 视频 App 无启动入口（monkey 报 No activities found）；游戏中心「我的 → 设置」直达「隐私开关设置 → 个性化推荐管理」 |
| 下拉搜索「搜索范围」 | 榜单、小说、购物等推荐项 | 待补 | 待补 | 该页是数据源列表（本机应用/相册等）；推荐项在「首页卡片管理」（推荐卡片等）和「功能管理」（搜索框提示词） |
| 小布建议 | — | — | — | 路径「OPPO AI → 小布建议」正常；资讯服务在「内容资讯」分组，行点击进二级页才有开关；服务行用文字「已开启」标注，非标准开关，`fast.py only/off` 在列表页无效 |
| OAID 广告跟踪列表 | — | — | — | 约 40 个 App、5 屏；用 250ms 慢滑翻页无效，需 120ms 快滑 |

### OPPO Pad Mini（OPD2515 / ColorOS 16.1.0）

以下来自 [Issue #9 的社区实测](https://github.com/rddmwmddr/android-ad-cleaner/issues/9)，尚无本机型整段自动脚本：

| 位置 | 差异与处理 |
|---|---|
| 软件商店 12.21.62 | 设置里没有「隐私」「服务管理」，不套用上面的 30 多项推广位清单，也不关闭下载更新或应用安全功能 |
| 浏览器 40.10.10.9 | 平板主页本来没有资讯流，不存在「主页设置 → 页面布局」。保留已开启的网站广告屏蔽；关闭开屏广告后，摇一摇可能只是变灰，不能算独立关闭成功 |
| 下拉搜索 | 先收起键盘，再从底部「设置」进入；直达 Activity 未导出时不绕权限。「账号与隐私」只是分组标题。「首页卡片管理」可关闭未下载应用推荐、应用建议小卡、热搜应用、精选推荐、热搜榜单、推荐卡片；应用建议、便捷服务和本机搜索数据源保留 |
| 小布建议 | 「内容资讯 → 资讯服务」是二级页；关闭资讯，保留赛事、出行等服务 |
| 任务栏 | 「设置 → 辅助功能 → 任务栏 → 任务栏显示内容 → 最近和建议应用」会显示建议应用。关闭也会移走最近应用，可能需要重新固定常用图标；由用户决定，不加入通用自动流程 |
| 广告组件 | 社区设备上没有 `com.opos.ads`、`com.heytap.pictorial`；检测不到就跳过，不找别的包替代 |

反馈还提到 `mcs_not_intercept_pkg` 通知豁免名单。这是待研究项，不能只凭包名判断修改后会影响哪些服务通知；当前不自动修改、不照抄整段名单，也不挂起推送传输层 `com.heytap.mcs`。

### OPPO Find X8s（PKT110 / ColorOS 17.0.0.102(CN01)）

以下来自 2026-10-28 在 PKT110 真机上的逐段实测，机型脚本：`recipes/oppo-PKT110/`。ColorOS 17 与上面 ColorOS 16 的入口差别较大，**不要照搬 ColorOS 16 的路径**。

| 位置 | 差异与处理 |
|---|---|
| 系统广告跟踪 | ColorOS 16 叫「隐私」，**ColorOS 17 改叫「隐私与安全」** → 设备标识与广告 → 广告跟踪。逐 App 一个开关、没有总开关，本机 96 个 App、分五屏；引擎的多屏翻页能读全 96 个，关完逐项回读 |
| 负一屏（速览） | 设置页里**没有「推荐服务」分组**，「搜索框提示词」「热点资讯」也找不到。内容资讯由小布建议的「内容资讯 → 资讯服务」管 |
| 下拉搜索 | 全局搜索的设置页 `com.heytap.quicksearchbox/.ui.activity.SearchSettingActivity` **没有导出**，`adb am start` 会被系统拒绝（SecurityException: not exported）；用应用自己的 scheme 打开：`am start -a android.intent.action.VIEW -d 'gs://search/setting'`。页里有 搜索范围 / 自定义搜索结果 / 搜索引擎 / 首页卡片管理 / 功能管理 / 消息管理 / 账号与隐私（**「账号与隐私」只是分组标题**，真正能点的是它下面的「隐私」子页）。已关闭：搜索范围里的 个性化推荐、精选资讯、搜索建议；功能管理里的 搜索框提示词；消息管理里的 消息通知；隐私里的 个性化推荐。**「便捷服务」和搜索范围里的榜单、小红书、购物等是内容源不是广告位，保持不动** |
| 首页卡片管理 | 这一页能关 应用建议、精选推荐、推荐卡片、热搜榜单、活动皮肤、热搜应用 等推荐位。**「未下载应用推荐」「应用建议小卡」是「应用建议」的子项：父开关一关，这两行就从页面上消失**，所以要先关子项再关父项；父项本来就是关的时，这两行压根不存在，只关父项。**推荐卡片全部关掉后，这一页就不再列出任何卡片**（2026-10-28 实测），脚本据此跳过并按已关闭处理 |
| 小布建议 | 设置 → OPPO AI → 小布建议。**「内容资讯」是分组标题，点它没反应**；真正的入口是它下面那一行「资讯服务」（显示「未开启」），点进去才是二级页里的开关。这一页还能进「场景服务」的 视界日报、小红书资讯，两项都在二级页里单独开关。快递、航班、日程提醒、商圈服务在同一页，保持不动 |
| 软件商店 | 设置页**没有「隐私」和「服务管理」**，只有 应用与服务 / 全部服务 / 下载更新设置 / 应用安全；「应用与服务」只是分组标题，点不动。商店首页的推荐流、活动弹窗无法关闭 |
| 浏览器 | 底部「我的」点进去是菜单浮层，里面没有「设置」；用公开入口 `am start -n com.heytap.browser/.settings.component.BrowserPreferencesPage` 直达。隐私 → 广告管理（开屏广告、资讯列表广告本机本来就是关的，**摇一摇广告在上级开关关掉后仍显示为开且点不动**，系统置灰，不单独点）；隐私 → 个性化管理 → 个性化广告推荐 |
| 主题商店 | 我的 → 设置 → 服务管理 → 消息与广告（消息通知、开屏广告）；我的 → 设置 → 隐私 → 个性化推荐设置。**「个性化推荐设置」点下去先弹确认框，确认后页面退回「设置」**，回读前要重新进一次，否则会把关成功的开关算成没关 |
| 视频 | 我的 → 设置 → **「个性化管理」**（不是 ColorOS 16 的「个性化内容管理」）；个性化广告推荐、个性化内容推荐 |
| 游戏中心 | 我的 → 先关掉「页面升级」弹窗的「我知道了」；**「设置」那一行的文字是「设置,有新通知」**，精确匹配找不到，要用包含匹配；设置 → 隐私开关设置 → 个性化推荐管理 → 个性化推荐 |
| 小布建议 | 见上一行；内容资讯、视界日报、小红书资讯三项在本机本来就是关的 |
| 应用建议 | 小布建议 → 其他 → **应用建议**（`com.oplus.metis` 的 `com.oplus.metis.v2.ui.settings.SettingActivity`）：搜索首页上那排「应用建议」卡片里，每个被推荐的应用一个开关（清单按本机已装应用变化，不写进机型脚本）。整页关掉，脚本按回读逐项确认 |
| 营销通知 | 渠道页在 `com.oplus.notificationmanager`，工具白名单已含该 Activity，26 条营销渠道能正常逐条关闭并复查 |

### 一加 Ace 5（PKG110 / ColorOS 16）

来源：[PR #3 社区实测](https://github.com/rddmwmddr/android-ad-cleaner/pull/3)，不是本仓库整段回归结果。

- 商店没有「隐私」「服务管理」；个性化推荐在「账号与隐私 → 隐私授权管理 → 个性化推荐」子页。
- 浏览器底栏没有文字标签；社区通过公开入口 `com.heytap.browser/.settings.component.BrowserPreferencesPage` 进入。视频无启动入口时跳过，游戏中心从「我的 → 设置 → 隐私开关设置 → 个性化推荐管理」进入。
- 搜索范围是本机数据源，保留；推荐项在首页卡片管理、功能管理。小布建议的「已开启」是文字状态，需要进二级页处理，不能直接当列表开关点击。

### 一加 Ace 2 Pro（PJA110 / ColorOS 14.0.0.812 / Android 14）

2026-10-25 真机执行，完整范围见[一加旧系统实测](../10-一加旧系统实测.md)。以下为最新源码适配，尚未进入 0.2.3 安装包。

- 系统路径为「权限与隐私 → 隐私 → 设备标识与广告 → 广告跟踪」，最后一页是逐应用状态列表；本次未自动处理。
- 软件商店 12.21.0：「我的 → 设置 → 隐私 → 个性化推荐」还需进入二级页，个性化推荐已关闭。联网后跨页关闭服务管理中的六个明确推广位，并回读其他服务开关未变；下载更新和风险检测保留。
- 浏览器 40.10.1.9：「我的 → 设置 → 隐私」可关闭个性化推荐，未找到参考脚本的「主页设置 / 广告管理」。
- 下拉搜索 11.31.4：「设置 → 账号与隐私 → 隐私」个性化推荐关闭；其他参考入口不等于已适配。
- 系统通知设置位于 `com.oplus.notificationmanager`，23 个营销渠道关闭并回读通过，应用总开关不变。联网后天气提醒重要级别变化但仍开启，差异见实测记录。
- 主题、视频、游戏中心、负一屏等仍有入口差异；专用脚本只列出已识别的有限范围，不沿用 ColorOS 16 的全部步骤冒充已验证。

本机经机主同意挂起广告服务、乐划和两个快应用组件后，仍观察到部分进程被重新拉起；收尾广告服务仍运行。挂起状态不能作为后台彻底停止的证明，详细状态与还原方法见上述实测记录。
## 一加 Ace 2（PHK110）
实测日期：2026-10-25；系统：`PHK110_16.0.5.1201(CN01)`，Android 16。
机型脚本：`recipes/oneplus-PHK110/recipe.py`，只运行与该版本匹配的五段：
首次人工路径操作之后，软件商店单段重跑 23 秒、五段整段重跑 77 秒；加入精确白名单及失败状态检查后，最终版整段重跑 85 秒、五段均 completed。均为已关闭状态下的幂等重跑，新增关闭项为 0，运行后 `finish` 将插电常亮恢复为 0。这不等于在恢复出厂或首次开启全部开关的手机上做过完整自动化验收。
```bash
python3 tool/run.py -s <序列号> recipe 广告跟踪 软件商店 浏览器首页 浏览器广告 浏览器个性化
python3 tool/run.py -s <序列号> finish
```
- **广告跟踪**：系统设置搜索“设备标识与广告”，点 `android:id/title` 的实际结果，再进入“广告跟踪”。不能把搜索框中相同的文字当成已进入目标页面。首次人工操作关闭了 41 个原本开启的开关，另 55 个原本已关闭；关闭跟踪不会直接减少广告数量。
- **软件商店**：已验证 `oppo.intent.action.APP_SETTINGS`（指定 `com.heytap.market`）可直接进入“应用与服务”→“服务管理”，不需要经过有账号信息的“我的”页。脚本只关闭 26 个明确的推广入口；未知项目保留。安装更新、普通游戏分类、风险检测、应用工具、客服、资产、AI 搜索等不动。
- **浏览器**：同一公开设置 Intent 指定 `com.heytap.browser` 可进入设置。主页设置→页面布局→简洁；隐私→广告管理，关闭开屏广告和资讯列表广告；隐私→个性化管理，关闭个性化优惠、广告推荐。不清缓存、历史、书签、密码，不改默认搜索引擎。
- **摇一摇广告**：两个上级广告开关关闭后，该开关仍可能报告 `checked=true`，但 `enabled=false`。脚本不单独点击它，不将它计为“独立关闭成功”。
- **动画与坐标**：该版本进入子页时，层级树曾短暂给出超出 1240 像素屏幕宽度的开关坐标。脚本等待活动、标题和坐标稳定，再操作开关。
- **通知渠道**：首次单独挑选 12 个明确营销渠道，11 个关闭；`com.heytap.mcs` 的 `push_oplus_category_content` 点后不生效，保留失败状态。渠道随已安装 App 和使用情况而变，不把本机渠道列表写进机型脚本。
- **广告包和快应用**：机主明确确认后，实测 `com.opos.ads`、`com.heytap.pictorial` 及两个快应用组件可挂起并读回状态。此动作不包含在机型脚本中，仍需逐台征得同意。乐划锁屏挂起会影响锁屏杂志；快应用挂起会阻止相应入口。不能据此声称第三方 App 广告全部消失。
- **未覆盖**：下拉搜索、负一屏、主题服务模式、视频和游戏中心。下拉搜索和小布建议的直达设置分别受非导出活动及系统权限保护，未绕过。主题当时是“基础服务”，未为去广告切换服务模式或同意协议。
本机型不包含 `pm suspend`、卸载、停用、通知渠道修改或开发者模式关闭。广告包、快应用与通知继续使用 `run.py` 标准流程；收尾始终运行 `finish`，并提醒机主关闭开发者模式。
